# CI-Assets

Die Corporate-Identity-Dateien der Hausverwaltung Müller GmbH werden vom
Auftraggeber bereitgestellt und hier eingespielt. Es wird kein Logo erzeugt,
generiert oder nachgezeichnet.

Erwartete Dateien:

| Datei | Verwendung | Hinweis |
| --- | --- | --- |
| `Logo_HVM.jpg` | Webheader, HVM-Rechnung | Seitenverhältnis 1320 x 1143 |
| `Logo_HVM.svg` | optional, bevorzugt für den Webheader | falls vorhanden |
| `favicon.ico` | Browser-Tab | optional |

Solange die Dateien fehlen, zeigt die Oberfläche einen neutralen Textplatzhalter
und der Adminbereich führt einen Livegang-Blocker.
